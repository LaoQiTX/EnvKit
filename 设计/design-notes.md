# envkit 界面设计

envkit 是面向 Windows 开发者的本地配置工具。本交付为 SVG 界面设计，全部内容为示例数据，不读取或修改本机变量与注册表。

## 交付内容

- 环境变量主界面：用户与系统作用域、搜索、导入导出、路径检查、变量列表和 PATH 路径详情。
- 注册表主界面：注册表键树、地址导航、值列表、类型与数据详情，以及关联环境变量入口。
- 两页各有浅色与深色 SVG。所有文字与形状均可编辑，图标嵌入 SVG，无外部资源依赖。
- index.html 为设计预览器，支持页面和主题切换、下载当前 SVG；侧栏的环境变量、注册表与主题入口也可切换设计稿。其余应用按钮是视觉设计占位。

## 设计语言

以克制的实用工具美学组织信息，自定义视觉设计，未宣称采用官方 Fluent UI 组件。参考 design-taste-frontend 的排版、对比度和一致性检查，以及 minimalist-ui 的平面层次原则。由于交付是 SVG 设计稿，不引入 React 组件系统。

- 画布：1600 × 1000。侧栏 228，详情栏 388，内容区域优先保留变量名和路径的可读性。
- 配色：蓝灰文字、冷白与浅蓝表面、钴蓝强调色；深色使用海军蓝表面和浅蓝强调色。黄色与红色只用于路径警告。
- 排版：Segoe UI / Microsoft YaHei 作为 UI 字体，Consolas 用于变量、类型与路径。
- 圆角：输入框和按钮 6，行选择 5，状态标签 4，工作区面板 7。
- 图标：Phosphor Icons Regular，MIT 许可。品牌括号标记为独立绘制。
- 设计参数：DESIGN_VARIANCE 4 / MOTION_INTENSITY 2 / VISUAL_DENSITY 7。

## 交互设计意图

列表选择后在右侧连续编辑；长 PATH 拆为带序号的条目。不可用项与重复项保留原位置，便于判断修复是否影响优先级。修改先进入待应用状态，再展示差异并生成备份。系统变量需要权限时应在应用阶段明确提示。注册表和环境变量入口共享相同信息结构。

## 样例一致性

用户变量 9 项。PATH 7 项，其中 1 项路径不存在，1 项与第 4 项重复。注册表仅展示一个键的 9 个示例值，不表示读取了本机实际配置。
